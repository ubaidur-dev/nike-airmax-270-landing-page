# Nike Air Max 270 - Interactive Landing Page
This is a custom-built, premium product showcase designed to bring the Nike Air Max 270 to life with a modern digital experience. I focused on creating a high-impact, dark-themed interface that balances bold typography with interactive elements while keeping the performance fast and fluid.

### Key Features
* **Custom UI Design:** A high-end aesthetic using a deep black and orange "Sunset" theme to match the iconic Air Max 270 colorway.
* **Interactive Mouse Tracking:** A custom JavaScript-powered radial glow that follows the cursor, adding depth and a 3D feel to the product.
* **Single-Line Hero Typography:** Engineered the "AIR MAX" header to remain on a single line with fluid scaling for a high-impact brand presence.
* **Device Optimized:** Fully responsive layout using CSS clamp() and Flexbox that adjusts perfectly from desktop to mobile screens.
* **Pro Marketing Copy:** Replaced generic text with professionally written, benefit-driven product descriptions to simulate a real-world brand launch.

### Why I Built This
Instead of a static portfolio piece, I wanted to demonstrate how interactive micro-interactions can elevate a user's brand experience. I handled everything from the typography hierarchy to the technical execution of the parallax glow, ensuring the site reflects the premium nature of the Nike brand.

### Tech Stack
* **HTML5:** Semantic structure for a solid and SEO-friendly web foundation.
* **CSS3:** Custom styling, radial gradients, and advanced positioning for the 3D-layered effect.
* **JavaScript:** Vanilla JS used for real-time DOM manipulation and mouse-tracking event listeners.
* **Google Fonts:** Integrated 'Orbitron' and 'Inter' to maintain a futuristic yet readable brand identity.

### How to Use
* Simply clone the repository and open the **index.html** file in any modern browser.
* The project is ready to go with **no complex** installation needed.
